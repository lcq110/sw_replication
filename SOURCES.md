# Sources and local adaptations

Source project `bsvar_hmsh`, commit `f79b86ebe620af1e7c8ea01d64ca5e5b086a1977`. The GPL-3 license is retained.

- `simulations/`: original `monte-carlo_rr/` top-level R and required C++ files. `bsvar_ms_wrap.R` is split into collection and `tables.R`, changing root paths only; statistics are unchanged.
- `estimations/model.R`, `estimate.R`, `normalise.R`: executable stages from `empirical_rr/e_{hmsh,msh,exh,sv}.R`. Keep the first 1e6 burn-in and 5e4 posterior draws; HMSH/MSH/EXH include one 2e5 Step 2 pass. Its original repetition count is unrecorded. Prior cases 1/2/3 follow `e_{hmsh,msh}_rob.R`, start from the baseline last draw, and retain the 2e5 + 5e4 stages. Paper `tab:sddr` uses cases 1 and 3.
- `estimations/out_*.R`: local paths, no manuscript copy/beep/global workspace clear. The selected reference shock is moved to row 1, and output extraction uses row 1 consistently. `out_sddr.R` assembles baseline plus the two published sensitivity columns into LaTeX; other figure layouts retain author calculations. Machine-dependent Section 4 speed comparisons are excluded.
- `forecasting/bsvars01.R`–`bsvars28.R` and `burnin/burnin_{hmsh,msh}.R`: ordinary author files from `forecasting_performance/forecasting_bsvars_R&R/`. Only the input data path and recursive starting-directory creation are adapted. They retain the original full-sample warm starts, truncated to each window, specifications, seeds and draw counts. No deployment/parallel launcher is copied.
- `forecasting/score.R`: joint mixture-density LPS and predictive-median MASE from the same author's `forecasting_performance/score_final_results.R`. Its 30-model rerun scores go to `outputs/origin_scores-rerun.csv`, preserving frozen inputs.
- `forecasting/make_forecasting_results.R` and `inputs/origin_scores.csv`: original plotting calculations and unchanged frozen 30-model scores from `forecasting_performance/forecasting_bsvars_R&R/forecasting_performance/`. The plot script now accepts optional score-file/output-directory arguments, allowing rerun figures without overwriting frozen inputs or mixing results.
- `forecasting/baselines.R`: a minimal sequential SV/EXH implementation following the same ordinary R&R warm-start/window procedure. The ordinary author scripts cover the 28 Markov-switching models; this file supplies the two additional benchmarks. Prediction specifications are cross-checked against `BPSSdata/Forecasting study/Full sample/models/{sv,EXH_covid6m}.R`: p=10, Gaussian, seed20241110; EXH defaults sigma_s=1/sigma_nu=3. The new windows use the existing seed formula with IDs29/30; full-sample warm draws and per-origin draw counts follow the ordinary R&R settings. It copies no deployment/chunking code.
- Input equivalence checks establish that all 622x10 values, variable order, stationary flags and 634 raw regime labels equal the supplied data. The real EXH distinction is the forecast prior (1/3 versus the empirical fit's 7/9). This does not establish equality of finite-chain or published forecast scores.
- `data/`: unchanged `empirical_rr/bpss21.rda` and regime labels. Author inputs have 622 transformed observations through October 2025, whereas manuscript text says September. This discrepancy is preserved for author confirmation.

The empirical C++ normaliser compares row(1) while moving the target shock to row(0), and leaves HMSH state fields unpermuted. The unmodified source is retained in `estimations/src/`. `align_reference.R` implements intended first-row minimum-SSE matching and synchronises shock fields. Only hyper column 1 (B/shocks) is permuted; column 2 belongs to unchanged reduced-form A. This is a disclosed correction, not a claim of numerical equality to legacy results. Reference-shock selection follows the paper's impact-FEVD criterion and must be checked for each new posterior.
